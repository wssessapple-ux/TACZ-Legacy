**✨ 0.7.0-alpha 内测（第一个含原创功能的版本）：**

- **第三人称动作动画（最值得期待的一项）**：不再是"枪直挺挺托在手里"。第三人称的持枪、行走、奔跑、蹲行、骑乘、瞄准、换弹、开火全部有真实动作，采用**三层动作叠加**（下层管腿、循环层管持枪走跑、一次性层管开火/换弹/近战），开火与近战由**实际动作触发**、不做每帧猜测，左手玩家自动镜像，切换带淡入不跳帧。**任何枪包都能动**——枪包自带动画就直接用；没写动画的枪按枪型自动借用默认包的通用动作，第三方枪包一行数据都不用改。**需要额外安装 PlayerAnimator 1.12.2 移植版**（可选前置，装了才生效，不装照旧、不会崩）。
- **自杀式无人机上线**：民用 / 军用两种型号，枪匠台可造——民用 = 铁锭 3 + 红石 1 + 火药 1 + 9mm 弹药 2；军用 = 铁锭 5 + 金锭 3 + 下界石英 2 + 7.62×39 弹药 3 + 手枪 ACRO 瞄准镜 1。锁定目标后飞向目标自爆，**爆炸不破坏方块**。
- **军用无人机限一架**：同一时间只能激活 1 架军用无人机，并带独立冷却，防止多架同爆刷伤害。
- **未加载区块实体清理**：新增区块卸载钩子，区块卸载时清掉该区块内的无人机等自定义实体，飞远后不再实体堆积卡服。
- **高版本枪包兼容增强**：现代 TaCZ Next（1.20+）格式枪包解析容错加强，贴图/模型/动画缺项不再整包崩。

> 第三人称动画的已知限制：**肘部不会弯曲**（1.12.2 没有 ModelPart，手臂只能整体刚性旋转）；**第一人称视角不受影响**，仍是原版手部渲染；枪包没自带动作的枪借用的是**通用姿势**（步枪/手枪/加特林三套），怪异手型（如火箭筒）可能略不贴合，可在枪包 display 里写 `player_animator_3rd` 单独指定。

**🔧 0.7.0.1-alpha 热修：**
- **疾跑中直接开火，不再强制停跑**：此前疾跑时点左键会出现"有开火反馈但没有子弹实体"——客户端在开火前把本地疾跑状态强清、服务端仍判定在疾跑并拒绝射击；同时冲刺过渡值缓降导致松手后仍有约 0.3 秒无法开火。第一版热修改成"开枪即停跑"，但按住左键会**每 tick 抹一次疾跑标志**，松手后必须重按 Ctrl 才能恢复冲刺，实测就是"开完枪强制减速"。现在改为**疾跑与射击互不干扰**：疾跑中直接开枪，速度不掉、Ctrl 不用重按，两侧判断一致、无死区。
- **疾跑不再打断换弹**：此前疾跑上升沿会取消装填，玩家体感就是"换弹总是失败"。现改为**边跑边换弹**（CoD 式手感），装填过程不受疾跑影响。
- **水下子弹有气泡尾迹了**：上游 TaCZ 子弹入水后每 tick 会吐出 4 个气泡，移植版此前完全没做，结果子弹一进水就"看不见了"，只剩射程短这个现象。现在补齐，入水能看到子弹在走。
- **水中阻力可配置**：新增 `WaterFriction`（`config/tacz/tacz-common.cfg` 的 `[ammo]` 段）。默认 **0.4**，与上游 TaCZ 完全一致（每 tick 速度乘 0.6，所以水里射程只有陆地的零头，这是上游原本的设计、不是 bug）。嫌水里打不远就调小，`0.15` 左右接近真实水阻。
- **每枪刷屏日志清理**：`[AoeTrace]` / `[AoeTraceDmg]` / `[KnockbackTrace]`（子弹命中、近战、爆炸）/ `[AmmoSync]`（每开一枪服务端+客户端各写一行）全部降级到 debug，普通游玩不再往日志里灌东西。

**🔧 0.7.0 同步修复：**
- **爆炸 AOE 不再炸自己**：爆炸判定跳过中心方块 + 微推步长，贴脸引爆不会把自己掀飞。
- **配件图标显示成 X**：配件 GUI 图标错位问题修复。
- **背包内收枪动作**：从背包切枪时的收枪动画补全，不再突兀消失。
- **ignite 配件真正生效**：燃烧类配件 modifier 接入弹道命中结算（此前只注册不消费）。
- **modifier 注册↔消费守门**：新增守门校验，杜绝"属性注册了但战斗逻辑没读"的假实装。
- **联机开枪广播瘦身**：开枪事件只同步 entityId + 枪械 ID，不再整把枪 NBT 全量广播，多人服带宽占用明显下降。
- **打空弹匣后补弹恢复**：弹药补给流程修复，打空后补弹不再卡死。
- **弹药箱里的弹药不再悬空**：箱子受重力/放置状态变化导致弹药浮空的问题修复。
- **爆炸子弹穿透不完整方块**：爆炸类子弹命中台阶、栅栏等不完整方块时的判定修复。
- **换弹期间不再禁枪**：换弹中的射击冷却拦截放宽，边换边打不再误拒。
- **高版本枪包"打一发弹匣就归零"**：`fuel`（燃料罐式）供弹被误按背包直读处理，导致"一个弹药物品只换一发"、打完一发弹匣直接清零。已按上游语义修正为**换弹消耗 1 个物品、把弹匣一次填满**（如 `yrzs` 近战包的汉剑：1 个灵力 = 50 发剑气）。

### ⚠️ 仍存在的问题（受限于 1.12.2 底层限制或仍在排查）

- **高倍镜黑屏/镜框消失**：1.12.2 老旧 OpenGL 渲染管线与现代渲染（FBO/后处理）的底层冲突。目前 0.8.0 已初步实现开镜出十字准星，但依然在攻坚。
- **临时解决方案**：请搭配 **Actinium** 模组使用，它可以缓解部分倍镜黑屏问题。请勿与 BetterFPS 同时使用，两者会冲突。
- **高倍镜特定操作崩溃**：目前仍在抓取崩溃日志，计划在 1.0.0 彻底解决。
- **走路开背包可能偶发第一人称动作异常**：等待反馈确认修复中。
- **性能问题**：部分场景帧率下降、内存占用偏高，后续将持续优化。

`TACZ-Legacy` 是 `TACZ` 的 **Minecraft 1.12.2 Forge 移植工程**，并采用 **Kotlin + RetroFuturaGradle** 技术栈。

## 项目目标

- 迁移并保持 TACZ 的核心玩法、交互与功能一致性
- 最大化复用现有美术素材与资源命名体系
- 让 1.20 时代的“模组数据包 / 枪包”尽可能平滑迁移并保持兼容
- 重构 1.12.2 渲染侧架构，提供可扩展的渲染管线

---

## 技术栈

- Minecraft Forge `1.12.2`（`14.23.5.2847`）
- Kotlin（Forgelin-Continuous）
- RetroFuturaGradle
- Sponge Mixin（通过 MixinBooter 接入）

# 开发者编译指南

## 环境准备



* JDK 8（用于编译模组代码）

* JDK 21（用于运行 Gradle 进程，RFG 1.4.9 强制要求）

* 推荐使用 IntelliJ IDEA

## 配置 Java 路径（必须）

打开根目录的 `gradle.properties`，在文件末尾添加以下内容（注意修改为你电脑上的实际安装路径）「macOS/Linux 用户请对应替换路径」：



```
org.gradle.java.home=C:\\Program Files\\Eclipse Adoptium\\jdk-21.0.12.101-hotspot
org.gradle.java.installations.paths=C:\\Program Files\\Eclipse Adoptium\\jdk-8.0.504.1-hotspot
```

## 配置 Gradle 镜像（国内网络必须）

打开 `gradle/wrapper/gradle-wrapper.properties`，将 `distributionUrl` 替换为国内镜像，否则会报 SSL 证书错误：



```
distributionUrl=https://mirrors.cloud.tencent.com/gradle/gradle-8.1.1-bin.zip
```

## 修复依赖与工具链

打开 `build.gradle.kts`，做以下两处修改：



1. 将第 19 行的 `id("com.gtnewhorizons.retrofuturagradle") version "1.3.34"` 改为 `"1.4.9"`（旧版已被仓库移除）。

2. 在 `java { toolchain { ... } }` 代码块中，将 `vendor.set(JvmVendorSpec.AZUL)` 改为 `vendor.set(JvmVendorSpec.ADOPTIUM)`。

## 开始构建

执行以下命令：



```
gradlew.bat setupDecompWorkspace
gradlew.bat build
```

构建成功的 JAR 文件将生成在 `build/libs/` 目录下。

- 纯编译检查：`./gradlew classes`
- 客户端加载烟测：`bash scripts/runclient_smoke.sh`

## 设计原则（迁移期）

1. **兼容优先**：先保证行为与数据兼容，再做结构升级。
2. **分层迁移**：资源/数据层、逻辑层、渲染层分阶段推进。
3. **可观测性**：关键系统在迁移期必须有日志与诊断开关。
4. **可回滚**：高风险改动（尤其渲染）要支持灰度开关。
5. **分离但不断裂 MC**：核心逻辑尽量去 MC 依赖以支持单测，同时保留清晰 MC 适配层。
